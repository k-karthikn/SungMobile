# Stage 4 — POCO manual verification

**18 October 2026 follow-up:** Use `Sung-0.5.1-stage4-debug.apk` (code 7) to verify the mini-player remains visible after opening an album or playlist and playing a song there. It should open Now Playing and return to the same collection with the mini-player still present. This APK has a new debug signing key; an existing installation signed by the old key must be uninstalled first. That removes its local data, which the owner agreed to. Future updates should use the new key without uninstalling. The original upgrade/data-retention step below applies only to the original code 6 APK signed by the old key.

Status: **accepted on 18 October 2026** after the owner reported Stage 4 working fine. This checklist remains the historical test scope. No USB connection was required.

1. **Fresh install and restart:** because the old signing key was lost, remove the old-key installation before installing code 7. Create a Like or playlist, change an appearance setting and form a queue. Restart the app and confirm they remain. Restored playback should wait for your Play action.
2. **Search:** type quickly, replace the query and switch Songs/Albums/Artists/Playlists. Results should correspond to the latest input. Typing previews alone should not add search history; submit or open a result, then check history. Clear the field and use a recent query.
3. **Back and rotation:** scroll down album/playlist results, open one, then return. Query, category, loaded rows and scroll should remain. Rotate in Search and in collection details; no second playback or unsolicited start should occur.
4. **Shared links:** in YouTube/YouTube Music choose Share → Sung, first while Sung is closed, then while it is already open/playing. Expect one choice/preview dialog and unchanged playback. Open a link with both `v=` and `list=` and check song/playlist choices. Cancel once and rotate: it should not reopen. Paste a supported link into Search as well.
5. **Timestamp:** paste `https://youtu.be/dQw4w9WgXcQ?t=60`. Open the preview; it should remain silent. Play all should start near 1:00. Tapping the song row should instead start from the beginning. Reject a malformed or non-YouTube URL with an understandable message.
6. **Collections:** open an album and a longer playlist, load another page, and try Play all, Shuffle all, Play next, Add to queue and Add to local playlist. Check source order and intentional duplicates where present. Queues/local saves should be independent snapshots. Like/add individual songs from their row menu.
7. **Cancel and partial content:** start loading a large collection and cancel; the current queue should stay unchanged. If a load fails (for example, briefly disable the network), expect Retry/Cancel or an explicit action using only the loaded subset. Reconnect and retry. A new queue choice must not later be replaced by an old loading operation. Refresh collection should work after a failed refresh.
8. **Artist limits:** open an artist. Channel videos must be labelled as such; unavailable artist catalogs should offer song search. A direct unsupported music album browse link should explain the limitation rather than start playback or silently search its URL.
9. **Home:** pin a playlist and like at least two songs. Check pinned shortcuts, Likes, Liked shuffle, View/Play/Save mix and Refresh mixes. Listen long enough to qualify history, then check Recently played and Recent mix. Enable Private mode: history-derived Home sections should disappear while Likes/pins remain. Clear listening history: its Home sections should disappear, including any old mix preview.
10. **Playback regression:** play a multi-song queue, leave Sung, lock the phone, use notification controls, then wait for automatic next track. Return and confirm one player and a coherent queue. Check pause, seek, stop, repeat and shuffle still behave as in Stage 3.

Report any failed item with the step, song/playlist URL, expected/actual behavior and a screenshot where useful. YouTube/network failures can vary by content and region; report the URL so the same case can be reproduced.
