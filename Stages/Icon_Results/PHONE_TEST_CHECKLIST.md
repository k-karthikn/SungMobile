# Launcher icon check — code 23

Install over code 22 without uninstalling.

1. On the POCO home screen and app drawer, check that the full music note is centered and not clipped by the launcher mask.
2. If your launcher offers a round icon shape, switch to it and check again.
3. Check dark/light wallpapers and themed icons if enabled. The app should use its normal colored icon rather than a solid monochrome mask.
4. Confirm the app still opens and your Likes, playlists and settings remain.

Visual/device verification belongs to the owner.
