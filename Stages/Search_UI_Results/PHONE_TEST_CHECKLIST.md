# Search UI — manual phone check (code 21)

Install over code 20 without uninstalling. Confirm Likes, playlists and settings remain.

1. Open Search. Check title, editable rounded field, category chips, search button and empty state in your chosen theme and with larger text.
2. Search a song. Heart a result, use plus to add it to a playlist or queue, then play it. Reopen Search and check the heart state.
3. Search albums, artists and playlists. Open each type; check Back, paging, retry and any provider notice.
4. Clear the query with X. Check the recent search rows, recall one and remove one. With Private mode, confirm search history respects its existing policy.
5. Paste/open a YouTube song or collection link. Check poor-network retry and leaving Search during a request. The mini-player should stay visible.
6. Enable Reduced Motion and switch theme; check chip/button transitions and legibility.

Visual and phone testing belong to the owner; no device installation was performed by Codex.
