# Theme

All design tokens live in **`qml/Theme.qml`** (a QML singleton). Colours are generated by **`src/m3color.cpp`**, motion curves by **`src/m3motion.cpp`**, shapes by **`src/m3shape.cpp`**. The rule of the project: *every number comes from Material 3's published tokens* (Jetpack Compose `material3/tokens/*.kt`, Material Color Utilities), with a comment saying where.

---

## 1. Colour

### Where the "seed" colour comes from (in priority order)

1. **Artwork accent** (Settings → Use artwork accent, off by default): a hidden 48 px `RoundedArt` decodes the current cover; `seedColor()` shrinks it to 24×24, drops pixels that are transparent, grey (saturation < 0.12), near-black (< 0.08) or near-white (> 0.92), builds a 24-bin hue histogram weighted by saturation, and returns the average colour of the heaviest bin. Monochrome covers return "transparent" → fall through.
2. **Chosen accent**: Default, Purple `#6750a4`, Green `#386a20`, Blue `#00658e`, Terracotta `#8f4c38`, Mauve `#7d5260`, Olive `#6b5f00`.
3. **Desktop palette**: theme = System and a Noctalia `.colors` file exists.
4. **Built-in default seed `#b75f38`** (warm terracotta).

### From seed to scheme

`app.colorScheme(seed, dark)` → C++ `m3::scheme(seed, dark, variant, contrast)` returns ~50 Material roles. Results cached (256 entries keyed by colour + dark + variant + contrast).

When the seed changes, `Theme.qml` does **not** jump: it builds 13 intermediate seeds (3 for the slower Content variant) interpolated in **Oklch**, computes a scheme for each, then animates `seedProgress` 0→1 on the **defaultEffects spring** (~166 ms, no overshoot), and every role is interpolated in Oklch between neighbouring schemes. Hue is interpolated the short way round.

### Contrast levels (Settings → Contrast)

0 = Standard, 0.5 = Medium, 1 = High. Each role has a contrast curve (low/normal/medium/high ratios), e.g.:

| Role curve | Standard | Medium | High |
| --- | --- | --- | --- |
| onSurface | 7 | 11 | 21 |
| onSurfaceVariant | 4.5 | 7 | 11 |
| primary (accent) | 4.5 | 7 | 7 |
| container | 1 | 3 | 4.5 |
| onContainer | 4.5 | 7 | 11 |
| outline | 3 | 4.5 | 7 |
| outlineVariant | 1 | 3 | 4.5 |

Surface tones move with contrast too (light: surface 98, containers 96/94/92/90 at standard; dark: surface 6, containers 4/10/12/17/22).

`Theme.textContrast` (used for text over pictures) = 4.5 → 7 → 11.

### Role names used by components (Theme property → Material role)

`background`, `surface`, `surfaceLow`→surfaceContainerLow, `container`→surfaceContainer, `high`→surfaceContainerHigh, `highest`, `text`→onSurface, `muted`→onSurfaceVariant, `outline`, `outlineVariant`, `primary`, `primaryText`→onPrimary, `primaryContainer`, `containerText`→onPrimaryContainer, `secondary`, `secondaryText`, `secondaryContainer`, `secondaryContainerText`, `tertiary…`, `inverseSurface`, `inverseSurfaceText`, `inversePrimary`, `error…`, `scrim` (32 % opacity), `primaryFixed…`, `focusRing` (=secondary), `textSelection` (primary at 40 %).

### Colour decisions worth copying

- **Selection and navigation use the secondary pair**, never tertiary: tertiary is the seed hue rotated, which over warm covers turns green and looks foreign. Menus use surfaceContainerLow, not an accent.
- **Dragged rows use the primary container pair** for the same reason.
- **Outline vs outlineVariant**: outline for boundaries that must stand alone (text field, switch track); outlineVariant for decorative dividers.
- **Text over images**: never on the raw picture. A scrim of the surface colour is laid over, and its strength is solved from the picture's pixels so the text keeps `textContrast` (see METHODS_AND_TECHNIQUES).

### Light / dark

`Theme.dark` = desktop palette's darkness when following Noctalia, else `app.theme == "dark"`, or System + Qt's `styleHints.colorScheme`.

### Noctalia mapping (`DesktopTheme`)

Reads INI keys from `noctalia.colors`: background=`Colors:View/BackgroundNormal`, surface=`Colors:Complementary/BackgroundNormal`, container=`Colors:Window/BackgroundNormal`, high=`Colors:Button/BackgroundNormal`, text=`Colors:View/ForegroundNormal`, muted=`Colors:View/ForegroundInactive`, primary=`Colors:Button/ForegroundActive`, primaryText=`Colors:View/DecorationHover`, primaryContainer=`Colors:Window/BackgroundAlternate`, containerText=`Colors:View/DecorationFocus`, secondary=`Colors:View/ForegroundLink`. Missing roles are derived from the desktop primary. Used verbatim only at Balanced + Standard.

## 7. Motion

Material springs (damping ratio ζ, stiffness k, mass 1) are converted in C++ into a duration (time to settle within 1 %) and a cubic-bezier spline that Qt animates on. Computed values:

| Token | Expressive ζ / k | ms | Overshoot | Standard ζ / k | ms |
| --- | --- | --- | --- | --- | --- |
| fastSpatial | 0.6 / 800 | 285 | ~9.5 % | 0.9 / 1400 | 161 |
| defaultSpatial | 0.8 / 380 | 328 | ~1.5 % | 0.9 / 700 | 228 |
| slowSpatial | 0.8 / 200 | 452 | ~1.5 % | 0.9 / 300 | 349 |
| fastEffects | 1.0 / 3800 | 108 | 0 | same | 108 |
| defaultEffects | 1.0 / 1600 | 166 | 0 | same | 166 |
| slowEffects | 1.0 / 800 | 235 | 0 | same | 235 |
| loadingMorph | 0.6 / 200 (1 % → 10 % threshold) | 298 | — | — | — |

Rules:
- **Spatial** springs move/resize things (they may overshoot). **Effects** springs carry colour and opacity (critically damped, can never pass through a wrong value).
- Where Compose uses a spring for the same component, Sung uses the same one, and the comment cites the Compose file and line.
- Settings → Motion: Expressive (default) or Standard. Settings → Animations off → every duration becomes 0, continuous animations stop.
- Things that follow a moving target (meter bars, visualizer ring) **integrate the spring per frame** with the same ζ/k instead of using a fitted curve.
- Aliases: `fast`=fastEffects, `normal`=defaultEffects, `slow`=slowEffects, enter/exit = fastEffects, `curve`=defaultSpatial.

Notable animations: play↔pause glyph morph (defaultEffects), play button pulse with bass (fastSpatial), switch thumb (fastSpatial), checkbox fill (defaultEffects in / fastEffects out) and tick draw (defaultSpatial), radio dot (fastSpatial), tab indicator slide (defaultSpatial), navigation indicator grow (defaultSpatial), FAB menu stagger (slowEffects), bottom sheet open (defaultSpatial) / close (fastEffects), drawer open (defaultSpatial) / close (fastEffects), cover crossfade (defaultEffects), ambient wash pulse (slowEffects), visualizer shape morph (slowSpatial), loading indicator (loadingMorph + 4,666 ms rotation), skeleton shimmer 1,500 ms diagonal wave, wavy progress 1 wavelength/s.

## 8. Icons

- **Material Symbols Rounded** SVGs at three optical sizes: 20 px (`_20` files, for ≤ 22 pt), 24 px (default), 40 px (`_40`, for > 32 pt). 138 files.
- Filled (FILL=1) by default; outlined (FILL=0) forms for state-carrying destinations: `home_outline`, `library_outline`, `heart_outline`, `pin_outline`. Toggle icons without a filled form (`shuffle`, `repeat`, `repeat_one`) switch to a **semibold (weight 600)** drawing when selected.
- The `Icon` component cross-fades between the outlined and filled layer (the fill axis), and sits on the text baseline (≈ 11.5 % below centre) when beside text.
- Rendering: custom `image://symbols/<name>/<points>/<hex ink>` provider renders the SVG once into a coverage mask (cache 512 KiB), then tints with `SourceIn`. QML `Image.cache` lets identical icons share one texture.

## 9. Other visual signatures

- **Wavy seek bar / progress**: active track drawn as a sine wave (4 dp stroke, 3 dp amplitude, 40 dp wavelength; 20 dp when indeterminate), 4 dp gap, stop dot; amplitude drops to 1 when paused; the wave travels one wavelength per second via a render-thread transform.
- **Ambient backdrop**: cover decoded small, CPU-blurred once, drawn oversized behind a surface-colour scrim (default dim 0.8, raised automatically if text contrast would fail); drifts slowly on full-bleed surfaces; swells with bass on slowEffects in the immersive player.
- **Skeletons** pulse with a diagonal travelling wave rather than flashing.
- **Playing indicator**: 5 bars, each chasing a frequency band on fastEffects.
