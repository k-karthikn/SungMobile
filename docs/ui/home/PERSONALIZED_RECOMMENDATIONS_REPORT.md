# Personalized Home implementation

Implemented on 27 October 2026. The optional **For you** song shelf appears above the existing provider rows when there are likes or permitted listening-history signals and enough songs to show. The existing Home shelves, mood chips, card actions, and refresh behavior remain in place. Disabling **Personalized Home** in Settings or entering Private mode hides the shelf; Private mode also cancels recommendation requests. No APK was built for this change.

The feature reads a bounded local profile from Room and ranks validated, distinct YouTube songs locally. It uses up to two liked or explicitly chosen songs as seeds for related-song lookup, with five results per seed. If there is listening history but no seed, it can request one additional general Home page. Feedback offers **More from this song** and **Hide from For you** on the selected recommendation. The small feedback map and opt-out setting are kept in DataStore and included in portable backups; old backups default to recommendations enabled with no feedback.

The ranking profile, history, likes, and feedback are not sent to YouTube as a batch. A related lookup does send the selected song ID, as disclosed in Settings. The profile reader respects Private mode and the listening-history policy. The coordinator bounds requests, cancels stale work, discards related candidates when their seed is removed, and retains ordinary Home content after recommendation failures.

Code is split between `core/model/discovery` (models and pure ranker), `core/data/recommendation` (bounded profile read), `core/data/settings` (preference and feedback storage), `core/youtube/home` (general candidate page), and `feature/home` (fetch coordinator, shelf UI, Settings section). No database schema change was needed.

Verification: model and YouTube tests, core data and app unit tests, Android lint, and `git diff --check` passed. Focused tests cover ranking, Private mode, feedback, seed changes, history-only general candidates, older backup format, and preserving original Home rows. A physical-device review remains useful for recommendation quality and the carousel at varied font sizes; it was not part of this code-only run.
