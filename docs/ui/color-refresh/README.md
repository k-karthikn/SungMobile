# Blue palette refresh (code 31)

The fixed **Blue** appearance now uses Material 3 Tonal Spot roles generated from `#789DFF` at normal contrast. This moves the dark scheme from cyan-tinted surfaces to near-neutral graphite (`surface` `#121318`, `surfaceContainer` `#1E1F25`) and uses periwinkle for the main accent (`primary` `#B2C5FF`). Light mode gets the corresponding roles from the same seed. Components continue to use `MaterialTheme.colorScheme` rather than page-specific colors, so selection, controls, lyrics, and navigation stay coordinated.

On Android 12+, **Wallpaper + Balanced** now uses Android's generated dynamic scheme directly. This matches the active Material You palette exposed to system apps and avoids trying to recreate it from only `WallpaperColors.primaryColor`. Android exposes up to three representative wallpaper colors, while its system scheme also reflects the device's chosen dynamic-color variant. Other Wallpaper palette styles remain custom MaterialKolor schemes: they use the wallpaper's primary representative color as the seed and intentionally can differ from system apps. If wallpaper colors are unavailable, they use the system scheme's primary role as a fallback seed.

The tables in `core/designsystem/.../SungColors.kt` were produced by Sung's Material 3 HCT/Tonal Spot generator, with all standard roles resolved together. The reference screenshots informed the seed and surface contrast; their exact pixels were not copied. Host tests check text contrast and ordered surface levels in both modes. Phone visual review remains with the owner.
