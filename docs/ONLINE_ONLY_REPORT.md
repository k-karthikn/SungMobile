# Online-only build after deferring Stage 7

On 18 October 2026, the owner deferred device-storage music and downloading because of their complexity. The resulting `0.8.1-online`, version code 13, worked on the owner's POCO. It is now superseded by the Stage 8 code 14 test build; see `STAGE8_REPORT.md`.

The Stage 7 source was moved to `deferred/stage7/source_snapshot/`, outside all Gradle source sets, then removed from the repository on 30 October 2026 at the owner's direction. The code 13 APK had no Device music or Downloads screens, actions, scanner, transfer worker, local-content resolver, audio-storage permission, notification permission, data-sync foreground service or WorkManager dependency. Playback resolved YouTube only. Lyrics and the accepted Stage 0–6 library/playback features remained in the build. The Stage 7 code 12 APK was removed with the `Stages/` archive and is no longer available in the working tree.

The app ID stays `com.karthi.sungmobile.stage0`, and the debug signing certificate is unchanged. Room schema version 4 opens both the accepted code 11 database (version 2) and the optional code 12 database (version 3). The 3→4 migration leaves Stage 7 tables physically intact but unused, so installing code 13 does not delete those records. Device-song Likes and playlist entries from code 12 are hidden in the online-only library but remain in the database for a possible later return. Existing settings keys are also left on disk but ignored. If a phone did run code 12, incomplete download jobs will no longer run and completed shared audio files will remain in device storage; the online-only app has no UI for them.

The offline host suite passed **137 tests**, with six opt-in live probes skipped and zero failures. Lint reported zero errors, and the APK build passed. A focused upgrade test opens a Stage 7 schema and confirms earlier library data and deferred tables survive. APK inspection found no Stage 7 screen, worker, local resolver or WorkManager classes, and no audio-file or notification permission. Package metadata reports code 13 and the retained app ID; the signing certificate matches accepted code 11. The assistant did not install or test code 13 on the phone. See `Stages/Online_Only_Results/PHONE_TEST_CHECKLIST.md` (files removed 30 October 2026) for the manual check.
